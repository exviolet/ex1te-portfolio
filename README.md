# ex1te job portfolio

Separate employer-facing portfolio for Бакытжан Избасаров / ex1te.

## Stack

```text
Astro 7
TypeScript 6
Custom CSS
Content Collections
No Tailwind in v1
No GSAP until one signature interaction is approved
```

## Routes

```text
/
/work
/work/steam-kz
/work/interactivelab
/work/sendoff
/about
/contact
/cv.pdf
```

## Commands

```bash
bun install
bun run dev
bun run verify
```

`verify` runs Astro check, a production build, and Node route/content tests.

## Current status

This is a navigable multi-route structural shell. Typography, palette, motion, domain, final contacts, English localization, InteractiveLAB final media, and the final CV are not approved yet.

`docs/design/reference-board.md` — the current and only source of visual direction, built on the reference set the user selected.
